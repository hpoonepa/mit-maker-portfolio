# P2Rank

Machine-learning prediction of ligand-binding pockets from protein structures.

- Upstream: <https://github.com/rdk/p2rank>
- License: MIT
- Input: PDB/mmCIF protein structure
- Output: pocket count, top-pocket probability and center, plus the input structure as mmCIF

The adapter pins the stable 2.5.1 release and remains beta until the Java runtime, packaged model, and output parser pass a live smoke test.
