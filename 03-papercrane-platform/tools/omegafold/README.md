# OmegaFold

MSA-free single-sequence protein structure prediction.

- Upstream: <https://github.com/HeliXonProtein/OmegaFold>
- License: Apache-2.0
- Input: one or more amino-acid sequences
- Output: mmCIF structure and confidence statistics

The image pins upstream commit `313c873ad190b64506a497c926649e15fcd88fcd`. It remains beta until the older CUDA stack and automatic checkpoint download pass a live Modal smoke test.
