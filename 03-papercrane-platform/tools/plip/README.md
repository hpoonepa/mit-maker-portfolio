# PLIP

Automated profiling of non-covalent interactions in protein-ligand complexes.

- Upstream: <https://github.com/pharmai/plip>
- License: GPL-2.0-only
- Input: a complex containing a ligand, or a protein structure plus SDF ligand
- Output: interaction counts by type and the analyzed complex as mmCIF

PLIP 3.0.0 is pinned. This integration remains beta until its OpenBabel dependency and XML report parser pass live smoke tests.
