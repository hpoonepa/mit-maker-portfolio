# ImmuneBuilder

Specialized structure prediction for antibodies, nanobodies, and T-cell receptors.

- Upstream: <https://github.com/oxpig/ImmuneBuilder>
- License: BSD-3-Clause
- Input: heavy/light, nanobody, or TCR alpha/beta sequences
- Output: predicted receptor structure as mmCIF

The adapter pins `ImmuneBuilder==1.2` and remains beta until model downloads and all three receptor modes pass live smoke tests.
