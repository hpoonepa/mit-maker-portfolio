# EvoEF2

Fast physics-based stability and protein-interface scoring through NeuroSnap's open SDK.

- Algorithm: <https://github.com/tommyhuangthu/EvoEF2> (MIT)
- Adapter API: <https://github.com/NeurosnapInc/neurosnap> (Apache-2.0)
- Input: PDB/mmCIF structure; optional two chain groups for binding energy
- Output: EvoEF2 stability/binding energy terms and the input structure as mmCIF

This is a beta integration until the pinned NeuroSnap package and artifact path pass a live Modal smoke test.
