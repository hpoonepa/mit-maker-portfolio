# AutoDock Vina

Open-source CPU docking of small molecules into protein receptors.

- Upstream: <https://github.com/ccsb-scripps/AutoDock-Vina>
- Preparation: <https://github.com/forlilab/Meeko>
- License: Apache-2.0
- Input: receptor structure and required SDF ligand or SMILES
- Output: docked protein-ligand complex as mmCIF and Vina energy terms

The adapter remains beta until receptor preparation, docking-box behavior, pose conversion, and R2 upload pass live smoke tests.
