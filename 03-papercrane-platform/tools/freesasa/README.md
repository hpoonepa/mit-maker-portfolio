# FreeSASA

Solvent-accessible surface-area calculation for protein structures.

- Upstream: <https://freesasa.github.io/>
- License: MIT
- Input: PDB/mmCIF protein structure
- Output: total, polar, apolar, backbone, and side-chain SASA plus the input structure as mmCIF

The integration pins the stable Python bindings and remains beta until representative structures pass a live artifact smoke test.
