# Original source layouts

These copies preserve the original `dynamics/` and `senba-sprint/` development
layouts alongside the earlier consolidated portfolio package. Source, tests,
configuration, notes, and small reference artifacts are included. Installed
dependencies, model weights, and large runtime datasets are obtained separately.

Upstream reference implementations retain their original attribution and
licenses. They are not presented as code authored for this portfolio. No training
or cloud computation was run while assembling this snapshot.
