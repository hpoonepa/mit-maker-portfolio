# Harsha Poonepalle · MIT Maker Portfolio

I build tools for protein design and match review. These three projects grew from problems I kept running into in my research and in squash.

[Build notes](docs/BUILD-NOTES.md) · [Code map](docs/CODEBASE-MAP.md)

This is a source-only archive. Submission videos, images and PDFs are provided separately.

| Project | What I built | Start with |
| --- | --- | --- |
| [MiniBinder](01-minibinder-design/) | A DWV binder-design workflow, campaign runners and structural checks, revised after the first 15 designs produced no confirmed binders. PRINCE contains my binding-site review work. | [Campaign and source guide](01-minibinder-design/docs/SOURCE-GUIDE.md) |
| [Paper Crane](03-papercrane-platform/) | The backend connecting protein-design tools, GPU jobs and saved results. This project also includes SENBA fine-tuning and the saved-data Studio viewer. | [Backend architecture](03-papercrane-platform/docs/portfolio-architecture.md) · [Dynamics](03-papercrane-platform/dynamics/) |
| [SquashVision](02-squash-vision/) | A match-review tool with tracking, court calibration, editable shot markers and explicit placement rules. | [Project and setup](02-squash-vision/README.md) |

The project pages explain what I changed, what I tested and what is still in progress. The code includes the available implementation, tests and retained research work. Start with the map rather than reading every file.

I worked with my Lambert iGEM team on MiniBinder and co-founded Paper Crane. Existing scientific models, research tools, libraries, datasets and footage retain their own credits and terms: [sources and licenses](docs/CITATIONS.md).
