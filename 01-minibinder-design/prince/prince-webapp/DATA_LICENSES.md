# Data attribution

The MIT license covers PRINCE code. Structural coordinates, source datasets, papers, fonts, and dependencies retain their own terms.

- **PDB coordinates:** RCSB PDB data are available under CC0; live lookups use the PDBe updated mmCIF endpoint. Cite the PDB entry and its associated structural publication when using a particular structure.
- **SAbDab-derived manifest:** chain-role metadata and derived benchmark labels originate in the SAbDab workflow documented in the companion model repository's `DATA_LICENSES.md`. Preserve that attribution and source receipt. The model repository now distinguishes the cited article license from the separately unverified database-snapshot redistribution grant.
- **Evaluation JSON:** PRINCE-derived measurements and provenance. These are a frozen retrospective study and should not be presented as results from a new run.
- **BepiPred comparison:** only PRINCE's comparison results and provenance are included. Upstream predictor code and weights are not redistributed.

Reference: Schneider C, Raybould MIJ, Deane CM. SAbDab in the age of biotherapeutics: updates including SAbDab-nano, the nanobody structure tracker. Nucleic Acids Research (2022), doi:10.1093/nar/gkab1050.

Workstation-specific path prefixes in documentary receipts have been normalized to relative paths. This does not change numerical results. Historical source hashes refer to the original experiment.
