# Source inventory

[CODEBASE-MAP.md](CODEBASE-MAP.md) explains the meaningful folders and entry points. [FOLDERS.csv](FOLDERS.csv) enumerates every directory containing files. [SOURCE-MANIFEST.json](SOURCE-MANIFEST.json) records the final file bytes, executable modes and source references.

The repository includes the three portfolio projects and their retained research code. MiniBinder’s GFP-only branch and unrelated operational material are outside this submission copy, with originals preserved. Large model weights, bulk trajectories, installed dependencies, credentials and private session/account records are not bundled.

Original Git histories were inspected and kept separately for review. All final assembly commits are current snapshot commits; retained source files are not a reconstructed development timeline.
